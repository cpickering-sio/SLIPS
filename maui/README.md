# Maui deployment (preliminary trial)

This folder holds code and data from a **preliminary Maui trial**. It was not
pursued as in depth as the main deployment: storm activity interfered with
conditions, and excess sedimentation confounded the results. The material is kept
here for reference and transparency rather than as a primary analysis.

## Contents
- `figures/` — figure-generation scripts.
- `stats/` — dry-mass statistics.
- `randomize_*.py` — randomization for the in-air and biofouling trials.
- `data/` — `maui_dry_mass.csv` (dry-mass measurements) and
  `maui_swell_cdip187_2026-03-29_2026-05-06.csv` (CDIP 187 swell series, HST,
  for the deployment window).
- `TUTORIAL_biofouling_pipeline.md` — walkthrough of the Maui biofouling pipeline.
